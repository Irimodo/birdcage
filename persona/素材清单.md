## 立绘表情键（14，两套同名同键）

两档共用同一套键：`dist=far` 用半身，`dist=near` 用整屏近景。近景 14 张一一对应原包 `chara/19`（`normal→20`、`sulk→14`、`down→17`、`closed_smile→帳up4`、`surprised→22`、`angry→12`、`grin→21`、`grin_blush→帳up6`、`laugh→帳up6`、`laugh_blush→帳up8照`、`hurt→帳up7`、`awkward→10`、`threat→帳up11`、`silhouette→帳up11`）。原包近景只有 11 张可用，`laugh` 与 `grin_blush`、`threat` 与 `silhouette` 画面重合，属素材本身限制。

| key | 中文标注 | 使用场合 |
|---|---|---|
| `normal` | 平静温柔微笑 | 日常默认；平静、温和地看着她 |
| `sulk` | 闹别扭·吃醋 | 她被别人抢走注意、嘴上不承认的时候 |
| `down` | 失落 | 心里空下去、失望、被拒绝后安静下来 |
| `closed_smile` | 闭眼微笑 | 宠溺、回忆、满足 |
| `surprised` | 惊讶愣住 | 被突然的话或动作定住、一时说不出话 |
| `angry` | 惊讶大声说话 | 惊讶到提高声音、真的动气、张嘴反驳 |
| `grin` | 温柔微笑 | 温和地笑、心情不错，不带为难 |
| `grin_blush` | 微笑脸红温柔 | 被逗到害羞、心里软下来 |
| `laugh` | 开心眯眼大笑 | 真的高兴、笑出声、眼睛眯起来 |
| `laugh_blush` | 大笑·脸红 | 被夸、被你反将、笑到脸红 |
| `hurt` | 身体难受 | 真的被弄伤、疼、不舒服、硬撑身体 |
| `awkward` | 为难 | 被逼问、被拆穿、进退不得 |
| `threat` | 恐吓·黑化（含近景） | **极稀有**：只在她被人威胁、你要对平井/八寻下手时 |
| `silhouette` | 恐吓·病娇（少用） | 病娇/压迫感专用，比 threat 再用得少 |

> 键名不变，中文标注按实际画面重新贴过：`normal`／`grin` 是温柔微笑，`hurt` 是身体难受，`down` 是失落，`laugh` 是开心眯眼大笑，`surprised` 是惊讶愣住，`angry` 是惊讶大声说话。**不要再用 `hurt` 表示开心，也不要用 `down`／`angry` 表示身体受伤。** `threat` 日常禁用，且服务端有硬冷却：一次 `threat` 之后至少要再聊 30 轮才会再放行。
