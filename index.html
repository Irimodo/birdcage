记 忆

这些是每次对话都会带给他的长期记忆。改一条、删一条都只影响那一条。

设 置

接入（模型接口）

OpenAI 兼容地址，填到 /v1 为止即可；程序自己补 /chat/completions。
只存在这台设备的浏览器里，不上传；换设备或清缓存要重新填。
带「思考」的模型会先花几百 token 想，正文容易被挤成空。这里调到 1200 以上更稳。

时间锚点

画面

只是默认值。对话里他自己会按剧情凑近或退回远景；这里选「近景」时，表情预览用的就是近景那套图。
直接在画面上点他的头（摸摸头）、脸、或衣角肩膀，他会当场有反应，也会记住刚才被碰过。
这里选的是默认值。对话中他会自己按剧情换背景、换表情、换歌，不用手动拨。

声音

发送

你打一句、再打一句，等这么多秒没新消息，他才一起回。填 0 就是发一条回一条。默认 8。

通知

切到后台时，回复写好会提醒你；前台不会打扰。
iPhone 要先“添加到主屏幕”，再从桌面打开。完全杀掉 App 后不会响；切后台、页面还在时才会提醒。

文字

备份

包含设置、记忆、历史、当前场景；不含 API Key。
会覆盖当前的设置、记忆、历史与场景；API Key 保留本机现在这把。

记忆与上下文

越大他越记得刚才说过什么，但提示词更长、更慢。默认 12。
填 30 就是每聊 30 轮（一问一答才算一轮），自动写成一篇帐的日记式记忆。填 0 关闭自动总结。
